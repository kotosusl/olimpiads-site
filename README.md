Запуск проекта
# Клиентская часть
Запускать из каталога store-demo-master.
## Установка npm
```
npm install
```
## Запуск приложения
```
npm run dev
```

# Серверная часть
Активируйте виртуальное окружение и запустите файл /store-demo-master/server/main_server.py.
## Запуск сервера
```
python /main_server.py
```

# Телеграм бот
Активируйте виртуальное окружение и запустите файл /store-demo-master/server/main_bot.py.
## Запуск бота в Telegram
```
pyhton /main_bot.py
```
